Requirements
============

* Operating Systems: Windows, 64-bit, >= 8GB RAM

* Python: Version 3.12, 3.13, 3.14 or 3.15. pyEMAPS 1.1.x supports Python 3.7.
* numpy: Version >= 2.0
* matplotlib: Version >= 3.8.4

``pip install pyemaps`` installs these, together with the matching *emaps* backend for
your Python version.
